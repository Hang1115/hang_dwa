# hang_dwa

C++14 的独立 DWA 局部规划库，不依赖 ROS。支持圆形车体、全向速度（vx/vy/wz）、参考路径和原始占据栅格的距离场。

## 构建

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build -j2
```

CMake 3.16 以上；目标为 `hang_dwa::hang_dwa`，通过 `add_subdirectory` 接入调用方，自动传递头文件路径及 C++14 要求。

## 调用约定

1. 地图更新时调用 `buildDistanceField(map, occupied_threshold, field)`。未知格和达到阈值的格子均作为障碍，原地图不膨胀；返回 false 时保留原输出。
2. 设置 `DwaConfig`，默认值在 `include/dwa_defaults.hpp`，调用 `isDwaConfigValid` 可独立验证配置。速度、加速度上限和可保证的制动减速度需要依据实际底盘设置。
3. `RobotState.pose`、参考路径、地图使用同一规划坐标系；`velocity` 是实际反馈的车体速度。若存在指令延迟，可填入 `last_command` 并置 `has_last_command=true`，让连续命令沿上一条指令采样；指令与反馈超出可达窗口时自动回退到反馈速度。取消或异常停车后清除该标志。
4. 调用方维护多段路径的 `path_start_index`（当前线段起点下标），只在已知进度附近向前搜索；新路径时重置为零。单段直线和单点目标无需更新索引。
5. 每个控制周期调用 `runDwa(state, path, field, config)`。`Success` 时执行 `best_velocity`；`GoalReached` 时输出为零。其余状态由调用方停车或重新规划。

算法没有时间戳、TF 或任务锁存，ROS 调用方负责输入有效性、数据新鲜度、失败停车和到达后的任务状态。当前只约束终点位置，不约束终点朝向。

## 终点与安全

终点速度上限综合剩余路径长度、真实终点距离、制动减速度和 `command_latency`。接近时衰减进度奖励，并增加终点位置评价。无法一步降至上限时选择动态窗口内的最大减速候选。到达同时要求位置、实际线速度和角速度满足容差。

所有候选独立检查完整预测轨迹和“延迟—速度过渡—本周期持速—完整制动”轨迹，安全检查不依赖用户是否配置障碍评分。制动轨迹从本次实际执行的短控制段开始，不要求把整个预测时间都持速后才制动。恒定速度预测采用精确平面运动积分，曲线与弦的误差加入检查余量。

距离场为精确欧氏格中心距离。`queryDistance` 保留格中心距离语义，`queryClearance` 额外扣除查询点到其格中心的偏移、障碍格半对角线和车体半径，并与地图边界净距取最小值。轨迹段按半格以内间距检查，同时按半采样间距膨胀车体，覆盖离散点之间的线段。

默认软评分为：路径均方偏差 ×2、归一化弧长进度 ×4、朝向均方误差 ×0.5、障碍接近程度 ×6、局部目标/真实终点误差 ×4。障碍评分混合最坏接近程度和平均接近程度，让逐渐远离障碍的轨迹获益。进度和朝向逐点投影，弧长变化受实际位移限制，避免折返路径的进度跳跃。

为限制单次规划工作量：控制/积分周期在 (0,1] 秒，指令延迟在 [0,5] 秒，采样数 1–31，预测步数 1–2000，预测时间及各轴最大速度对应的制动时间不超过 60 秒。实际控制频率还取决于地图、路径和采样规模。

安全结论依赖圆形车体模型、有效地图和真实的制动/延迟参数；距离场与段检查采取保守余量，狭窄通道可能被拒绝。移动障碍和局部极小仍需要上层重规划。

## 回归测试

```bash
cmake -S . -B /tmp/hang-dwa-check -DCMAKE_BUILD_TYPE=Release -DHANG_DWA_BUILD_TESTS=ON
cmake --build /tmp/hang-dwa-check -j2
(cd /tmp/hang-dwa-check && ctest --output-on-failure)
```

覆盖精确距离场与暴力欧氏距离对照、离散点之间的薄障碍、车体越界、旋转地图、未知区、障碍脱离评分、折返路径投影、零权重/自定义评价表下的硬安全、延迟和制动尾迹、短距离/高速/延迟闭环、过冲后的回到目标，以及绕障路径收敛。
